# AGENTS.md — правила работы над сервисом 3DMP (репозиторий `saas`)

## Язык общения
- Все рассуждения, пояснения, комментарии и финальные ответы — **только на русском языке**.
- Технические термины, имена файлов/функций и код — латиницей, как принято.

## Проект
- Рабочая папка: `SAAS/` — рабочий сервис экосистемы 3DMP (не рекламный лендинг, а инструмент-сервис).
- Стек: **vanilla HTML/CSS/JS** + `@supabase/supabase-js` (CDN), **без сборки и фреймворков**.
- Бэкенд/БД: **Supabase** (PostgreSQL + RLS + Storage), проект `saas`.
- Вход: **собственный** — логин/пароль (bcrypt в Postgres), сессии-токены, данные через RPC (не Supabase Auth/email).
- Публикация: заливка по FTP в серверную папку `sapfir.eu\saas` → `https://sapfir.eu/saas/`.
- Репозиторий: `https://github.com/marat-beep/saas` (ветка `main`).

## Границы (не трогать)
- `project/` — статические прототипы экосистемы 3DMP: **отдельный проект**, не изменять.
- `НОРМ_РАЗРАБ/` — проект «Нормирование PRO» (`norms_*`), его git-репозиторий: **не трогать**.
- Не затрагивать схемы `gravirovka`, `norms_*`, `public.orders`, `public.role_passwords` и чужие ключи/URL.
- Работать **только внутри `SAAS/`**.

## Безопасность
- В клиентском коде допустим только **publishable/anon** ключ (публичный по дизайну); доступ ограничивается **RLS**.
- `service_role` / `sb_secret_*` / DB-пароль — **никогда** в клиент и **никогда** в коммит; только локальный `.env` (уже в `.gitignore`).

## Правила изменений
- Схема БД — только через миграции `supabase/migrations/NNNN_*.sql`.
- После правок проверять: баланс скобок в JS, соответствие `id` HTML/JS, валидность путей.
- Секреты не логировать и не коммитить. Коммит и push — только по явной просьбе.
