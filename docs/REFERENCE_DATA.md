# Справочники (reference data): что добавить в систему

_Реестр рекомендуемых справочников для 3DMP Service (R5). Источники — открытые (ГОСТ/ISO, Wikipedia G-code и др.). Часть заводится сидом `app_seed_reference_dicts` (миграция 0259), остальное — план (PROP-30…33 в `tools/proposals.js`)._

Типы хранения:
- **Системные** (жёстко в коде/БД, неизменяемы пользователем) — например, единицы, валюты.
- **Настраиваемые** (`app_dictionaries`/`app_dictionary_items`, редактируются) — виды оборудования, причины простоев и т.п.
- **Большие отраслевые** (отдельные таблицы с атрибутами) — материалы, оснастка, инструмент, системы ЧПУ (нужны доп. поля).

## 1. Уже реализовано (сид 0259, «Загрузить базовые»)
`app_seed_reference_dicts(p_token)` создаёт для организации типовые словари (идемпотентно):
- **Виды оборудования** (`machine_kinds`): токарный, фрезерный, сверлильный, шлифовальный, электроэрозионный, лазерный, пресс, гибочный.
- **Системы ЧПУ** (`cnc_systems`): FANUC, Siemens Sinumerik, Heidenhain, Mitsubishi, Mazak Mazatrol, Okuma OSP, Haas NGC.
- **Виды инструмента** (`tool_kinds`): концевая фреза, сверло, метчик, развёртка, токарный резец, отрезной резец, расточная головка.
- **Причины простоев** (`downtime_reasons`): нет материала, поломка, переналадка, нет программы, нет оператора, плановое ТО.
- **Виды дефектов** (`defect_kinds`): размер, шероховатость, трещина, задир, раковина, биение, заусенец.
- **Каналы связи** (`contact_channels`): телефон, e-mail, Telegram, WhatsApp, чат.
- **Источники заявок** (`request_sources`): сайт, телефон, e-mail, менеджер, дилер, тендер.

## 2. Рекомендуется добавить (настраиваемые)

### Оборудование и ЧПУ
- **Типы стоек ЧПУ** (расширение): Fanuc 0i/18i/30i/31i, Sinumerik 828D/840D/808D, Heidenhain TNC 620/640, Mitsubishi M70/M80, Fagor, Bosch Rexroth, GSK.
- **Форматы/языки УП**: ISO-6983 (G-code), RS-274, Heidenhain Klartext, Mazatrol, Sinumerik ShopMill/ShopTurn, Haas IPS (диалоговый).
- **Оси и кинематика**: 3/4/5 осей, токарно-фрезерные, портальные, обрабатывающие центры.
- **Точность/класс станка**: нормальная/повышенная/высокая/особо высокая.
- **G-коды (справочник инструкции)**: G00 ускоренное, G01 линейная, G02/G03 круговая, G04 пауза, G17/18/19 плоскости, G20/21 дюймы/мм, G28 возврат, G40/41/42 коррекция, G43 компенсация длины, G54–G59 рабочие смещения, G80–G89 циклы (сверление/резьба/расточка), G90/G91 абсолют/инкремент, G94/G95 подача/об-мин, G96/G97 скорость резания, G98/G99 возврат.
- **M-коды**: M00 стоп, M01 опциональный стоп, M02/M30 конец, M03/M04/M05 шпиндель, M06 смена инструмента, M08/M09 СОЖ, M98/M99 вызов подпрограммы.
- **Регламенты ЧПУ/инструкции**: ТБ при работе на станке, порядок наладки, привязка нуля, проверка УП «по воздуху», регламент ТО станка.

### Инструмент и оснастка
- **Типы оснастки**: патрон, цанга, тиски, призмы, люнет, магнитная плита, делительная головка, кондуктор, штамп, пресс-форма.
- **Материалы工具 режущей части**: HSS, твердый сплав (P/M/K/H/S), CBN, алмаз, керамика.
- **Износ/переточка**: норматив стойкости, число переточек, критерий износа.

### Материалы и стандарты
- **Группы материалов**: конструкционные/легированные/нержавеющие/инструментальные стали, чугуны, алюминий, медь/латунь, титан, пластмассы.
- **Стандарты**: ГОСТ (марки), ISO, DIN; ЕСКД (`ГОСТ 2.xxx`), ЕСТД (`ГОСТ 3.xxx`), ОРД (`ГОСТ Р 7.0.97-2016`).
- **Единицы**: шт, кг, г, м, мм, м², м³, л, мин, ч, комплект, к-т.
- **Валюты**: RUB, USD, EUR, CNY; **ставки налогов**: 0/5/7/10/20 %.
- **Условия поставки**: EXW, FCA, FOB, CIF, DAP, DDP (Incoterms 2020).

### Производство и качество
- **Типы операций**: токарная, фрезерная, сверлильная, шлифовальная, ЭЭО, слесарная, сборочная, контрольная, термическая, гальваническая.
- **Причины простоев** (расширенно) и **виды дефектов** (расширенно, с привязкой к КТПП).
- **Виды брака/несоответствий** и **причины (root cause)** для CAPA.
- **Типы контроля**: входной, операционный, приёмочный, летучий, инспекционный.
- **Категории затрат**: материал, оплата труда, накладные, энергия, инструмент, амортизация, транспорт, прочие.
- **Типы упаковки/тары**: коробка, паллета, ящик, обрешётка, контейнер, без упаковки.

### Кадры и квалификации
- **Разряды/квалификации**: 1–6 разряд, инженер-технолог, мастер, наладчик, оператор ЧПУ, контролёр ОТК.
- **Виды смен/графики**: 1/2/3 смены, скользящий, вахта.
- **Причины выбытия** сотрудников (для аналитики текучести).

### Документооборот
- **Виды документов**: чертёж, спецификация, схема, ведомость, ТП/МК/КТП, накладная, ТТН, счёт, акт, договор, сертификат, декларация, протокол испытаний, ОРД.
- **Виды корреспонденции** (ЭДО/КЭДО): входящий, исходящий, внутренний, организационно-распорядительный.
- **Статусы/маршруты согласования** (типовые), **основания** (договор/заявка/приказ).

### CRM/продажи
- **Стадии воронки** (типовые): лид → квалификация → КП → переговоры → выиграно/проиграно.
- **Источники лидов** и **каналы**: сайт, реклама, рекомендация, тендер, дилер.
- **Причины отказа** клиента (для аналитики продаж).
- **Типы клиентов/сегменты**: ключевой, постоянный, разовый, дилер, ГП (гособоронзаказ).

## 3. Что можно подтянуть из открытых источников
- **G/M-коды** — публичные справочники (Haas/FANUC; Wikipedia G-code, canned cycles) → завести как «Инструкции ЧПУ» (справочник/БЗ).
- **Номера ГОСТ** (ЕСКД/ЕСТД/ОРД) — открытые реестры стандартов → завести как справочник «Стандарты».
- **Марки материалов** (ГОСТ/ISO/DIN) — открытые таблицы марок → завести в «Материалы».

## 4. Как хранить
- Мелкие списки — **настраиваемые справочники** (`app_dictionaries`), сид + ручное дополнение.
- Оборудование/инструмент/**стойки ЧПУ** — отдельные таблицы с атрибутами (модель, оси, точность, постпроцессор) + связь со справочником.
- Инструкции/G-коды — в **базе знаний** (`app_knowledge`) с тегами, доступ из «Инструкций».

## 5. Доступность и использование (как пользователь находит и применяет)

**Где найти:** модуль **«Настраиваемые справочники»** (`apps/dicts`, в хабе — контур «Платформа», доступен в боковом меню). Связан с **«Основными справочниками»** (`apps/registry`) взаимными ссылками. Кнопка **«Загрузить базовые»** создаёт типовые словари; список показывает счётчик значений; у каждого — кнопка **⧉ код** (копировать) и подсказка **«используется: …»**.

**Где применяются (карта «справочник → модуль»):**

| Справочник (код) | Где используется |
|---|---|
| `machine_kinds` | Справочники → Оборудование |
| `cnc_systems` | Справочники → Оборудование (системы ЧПУ) |
| `tool_kinds` | Инструмент, Оснастка |
| `downtime_reasons` | **OEE** (поле «Причина простоя» — подсказки), MES |
| `defect_kinds` | ОТК/Качество, CAPA |
| `contact_channels` | CRM, Сервис |
| `request_sources` | **Заявки**, **CRM** (поле «Источник» — подсказки) |
| `doc_type` | Конструктор документов |
| `loss_type` | Бережливое производство |
| `setup_type` | Наладка |
| `supplier_category` | Поставщики |
| `marketplace_process` | Маркетплейс мощностей |
| `teo_line_kind` | ТЭО |

**Как подставляются в формы:** модули читают значения по коду через `app_dict_items_by_code`; текстовые поля получают подсказки через `AppUI.dictSuggest(fieldId, code)` (datalist — можно выбрать или ввести своё). Уже подключено: **OEE** (`downtime_reasons`), **Заявки** и **CRM** (`request_sources`). Подключение новых — по мере надобности (см. PROP-34).
