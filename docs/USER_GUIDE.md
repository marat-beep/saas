# USER_GUIDE — руководство пользователя 3DMP Service

> Черновик. Полное наполнение — волна **W37**. Адрес сервиса: **https://sapfir.eu/saas/**.

## 1. Вход
1. Откройте `https://sapfir.eu/saas/` → **Вход**.
2. Логин и пароль (выдаёт администратор). Сессия хранится в браузере.
3. Демо: admin/admin, owner/owner, manager/manager, master/master, qc/otk, supply/supply, support/support, client2/client2.

## 2. Хаб (главная)
- Каталог модулей по группам (Производство, Продажи, Качество, Экономика, Платформа, Кадры…).
- Поиск и фильтры, раскрытие групп, «избранное» (в плане v3 — W29).
- Переход в модуль — клик по карточке.

## 3. Типовой экран модуля
- Верхняя панель: **Тема**, **Сервер**, **Вход/Пользователь**, выход.
- Боковое меню (☰) — навигация по сервису; на телефоне — drawer.
- Кнопка **«Назад»** и «хлебные крошки» (в плане v3 — W30).
- Таблицы/карточки, кнопки действий, отчёты (**PDF/DOC/CSV**), часто — вкладки.

## 4. По ролям (что видно)
- **admin/owner** — админ-разделы, тарифы/биллинг, права, холдинг, бухгалтерия.
- **manager** — заявки, производство/планирование, закупки/склад, отчёты, задачи/ЭДО/КЭДО/EHS.
- **master/technologist/operator** — MES, наряды, терминал, IIoT/OEE, инструмент.
- **qc** — ОТК, качество, претензии, паспорта.
- **supply** — закупки, склад, поставщики, логистика.
- **supplier/client** — порталы поставщика/заказчика (ограниченный набор).

## 5. Частые сценарии
- **Новая заявка:** Заявки → «＋» → заполнить → сохранить; далее КП/договор/производство.
- **Наряд/производство:** Производство/MES → создать наряд → операции → статусы.
- **Склад:** Склад → приход/расход → адрес/партия; при необходимости — мастер (W32).
- **Отчёт:** модуль → «Отчёт» (PDF/CSV) или Отчёты и экспорт → выбрать набор → сформировать.
- **Задача:** Задачи и проекты → проект → задача (канбан) → время/обсуждение (@логин).
- **Документ (ЭДО):** Документооборот → «＋ документ» → зарегистрировать → поручения/связи.
- **Ознакомление (КЭДО):** личный кабинет → документ → подписать (ПЭП).

## 6. Уведомления и поддержка
- Уведомления — «колокольчик»/модуль объявлений; почта/Telegram/SMS — через интеграции.
- Поддержка — модуль «Служба поддержки»; идея/ошибка — «Баг-бокс»; замечание к странице — «Замечания».
- База знаний/гид — «Гид по системе», поиск по БЗ.

## 7. Офлайн и телефон
- Сервис — PWA: можно «Установить приложение» на телефон.
- Офлайн-режим и мини-приложения модулей — в плане v3 (W31/W36).

## 8. Безопасность
- Не передавайте пароль; сессия завершается кнопкой «Выйти».
- При подозрении на доступ — сообщите администратору (сброс пароля/сессии).
