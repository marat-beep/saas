# PLAN_WAVES — полный план волн обновления и развития 3DMP Service

Назначение: исполнять работы **большими шагами (волнами)** с коротким подтверждением («дальше»).
Документ дополняет `BACKLOG.md` (очередь и статусы) и `AUDIT_BACKLOG.md` (детали контуров).

## 0. Механизм исполнения (важно)
- **Одна волна = один большой шаг**: миграция + RPC + UI + каталог/БЗ + версии + коммит/пуш + отметки в `BACKLOG.md`.
- **Подтверждение:** достаточно слова «дальше» — агент берёт следующую волну из этого документа и выполняет целиком.
- **Статусы:** в `BACKLOG.md` §3 и в этом файле (☐ → ☑). План не теряется — он в репозитории.
- **Инварианты:** русский язык; светлая палитра, акцент `#10b981`, тёмная — опция; `?v=N`; UTF-8 для SQL; `apply_all.sql` пересобирать; смоук после миграций; доки в конце.
