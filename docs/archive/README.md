# docs/archive — исторические материалы

Здесь лежат устаревшие/неактуальные документы, сохранённые для истории. В основной
работе они не используются — **единственный источник правды: `docs/BACKLOG.md`** (план и журнал),
актуальные гайды — в `docs/` (MODULE_STANDARD, MODULES_CATALOG, PROMPT_NEW_CHAT и др.).

Попали сюда как дубли/заменённые (см. PROP-06 в `tools/proposals.js`):

- `PLAN_UPDATE_V4.md` — устаревший план обновления (заменён BACKLOG + PLAN_UPDATE_V5).
- `PROMPT_MODULES_DASHBOARD.md` — ранний промт по дашборду (актуальный генератор — `tools/gen-modules-page.js`).
- `PROMPT_MODULES_PAGE.md` — ранний промт по странице модулей.

При появлении новых исторических документов — переносить сюда с коротким пояснением.
