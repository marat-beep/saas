## 0. Как читать план
- Каждая волна `Xn` = один самодостаточный инкремент (пакет: миграция → RPC → UI → роли → связи → тесты → доки).
- В колонке «Артефакты» — предлагаемые имена таблиц/RPC/ассетов (по конвенции `app_<сущность>_*`).
- Статус: ☐ — не начато; ☑ — закрыто (заполняется по факту).
- Волны сгруппированы по контурам; **фокусные** (A–E) расписаны по модулям детально, прочие — сводно.
