## W31. Мини-мобильные приложения к каждому модулю (M–L)
**Цель:** быстрый «мобильный» доступ к ключевым функциям модуля (по мотивам лёгких приложений ELMA/Bitrix).
- Реестр «быстрых действий» в каталоге (`quick: []`): 3–5 ключевых операций на модуль.
- Мобильный режим модуля (`?mobile=1` / media-query): крупные тач-действия, минимум «тяжёлого» UI, либо deep-link на главную функцию.
- Офлайн: постановка операций в очередь (`offline-queue.js`).
- Артефакты: `assets/js/mobile.js` (каркас), метаданные `quick` в `catalog.js`, точки входа в модулях.
- **DoD:** с телефона доступны ключевые операции модуля; офлайн-отправка; PWA-установка.
- Оценка: **M–L**. Зависимости: W29/W30, PWA (есть).

## W32. Мастера (wizards) для справочников и операций (M)
**Цель:** пошаговые мастера для типовых сценариев (как «мастера» 1С/ELMA).
- Движок `assets/js/wizard.js`: шаги, валидация, прогресс, черновик, «Назад/Далее/Готово».
- Пилоты: создание позиции НСИ; добавление инструмента/экземпляра; приёмка на склад (адрес/партия); запуск процесса (workflow); кадровый документ; заявка на перевозку.
- Артефакты: `wizard.js`, мастера в `apps/mdm`, `tooling`, `warehouse`, `workflow`, `kedo`, `logistics`.
- **DoD:** мастер проводит по шагам, валидирует, создаёт сущность (RPC); можно прервать/продолжить.
- Оценка: **M**. Зависимости: W15 (workflow/forms), W18b (НСИ).

## W35. Маркетплейс-расширения (M–L)
**Цель:** реестр расширений/шаблонов с установкой по тенанту (декларативно, без произвольного JS).
- `app_extensions` (манифест: тип connector|template|report|dataset|kb|widget, версия, зависимости, права), `app_extension_installs` (tenant, ext, version, enabled).
- Установка/включение через флаги (`tenants.features`), права (`app_access`), аудит; UI в `apps/marketplace`.
- Интеграционные расширения — через `app_integrations` (воркер `backend-example`).
- **DoD:** каталог расширений; установка по тенанту с ролевым контролем; включение подтягивает точки интеграции; аудит.
- Оценка: **M–L**. Зависимости: W17, W18b, W15.

## W36. Мобильное офлайн-приложение (L)
**Цель:** полноценный офлайн (чтение+запись) на PWA.
- IndexedDB-кэш справочников и рабочих списков; офлайн-очередь мутаций с идемпотентностью и разрешением конфликтов; скан QR/ШК (камера/USB), фото, геометка.

- **DoD:** ключевые операции без сети с последующей синхронизацией без потерь; скан/фото; PWA-установка.
- Оценка: **L**. Зависимости: W31, PWA.
