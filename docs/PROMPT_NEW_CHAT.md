Проект 3DMP — рабочий веб-сервис производственной компании (vanilla HTML/CSS/JS + Supabase, без сборки).
Рабочая папка: `SAAS/` (локально) → деплой по FTP в `sapfir.eu\saas` (строчными) → https://sapfir.eu/saas/.
Репозиторий: github.com/marat-beep/saas (ветка main). Backend: Supabase `zfkbzzmtbrueaksfaqbf` (вход логин/пароль bcrypt, сессии-токены, данные через RPC).
Инструмент применения SQL: `powershell -File tools\apply-migration.ps1 -File supabase\migrations\NNNN_*.sql -Token sbp_…` (токен вводится вручную и отзывается).
