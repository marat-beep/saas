# BACKLOG — единый план обновлений и развития 3DMP Service

> Это **единственный источник правды по плану работ**. Он лежит в репозитории (`SAAS/docs/BACKLOG.md`) и не теряется между чатами.
> **Начало сессии:** прочитай этот файл, выбери верхний незакрытый пункт из §3 и работай по нему.
> **Конец сессии:** обнови статусы пунктов (и краткий журнал в §5), затем `PLAN.md`/`PROMPTS.md` при необходимости.

## 2. Правила и DoD (не нарушать)
- Только светлая цветовая схема по умолчанию; тёмная — доп. режим. **Палитру не менять.**
- SQL через Management API — **только UTF-8 телом**. Миграции идемпотентны; при смене типа `drop function`; в plpgsql с `RETURNS TABLE(...id...)` — `#variable_conflict use_column`; после миграции пересобрать `apply_all.sql`.
- Модули по `docs/MODULE_STANDARD.md` + `docs/MODULE_GUIDE.md`; карточка в `catalog.js`; БЗ; версии `?v=N`.
- DoD: миграция (применена) → смоук → UI → каталог/БЗ → версии → коммит/пуш → доки (`STATUS/NOTES/PROMPTS`).
