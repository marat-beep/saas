Справочники (настраиваемые)

Единые списки/варианты для самостоятельного наполнения (категории, виды, типы).
Контур: ЭкосистемаОблако · роли · уведомления
Что вы получаете

Результат для компании

🗂

Настраиваемые справочники: организация сама создаёт списки (код → значения-варианты) и использует их в выпадающих списках модулей через app_dict_items_by_code.

Возможности

Какие функции выполняются

  • Создание справочников (код + название)
  • Значения (код → название, порядок, активность)
  • Предзаполнены: категории поставщиков, виды потерь, типы наладок, упаковка, этикетки
  • API для модулей: app_dict_items_by_code

Зачем это нужно

Какие проблемы решает

  • Нет единого места для идей и прототипов
  • Сложно оценить объём расширения
  • Концепты теряются между сессиями
⚙️

Как реализовано

Модуль работает в облачном сервисе: данные хранятся в защищённой базе (Postgres), доступ — по ролям, обмен — через внутренние функции. Отдельной установки и обслуживания не требуется.
