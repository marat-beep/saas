Прогноз загрузки

Загрузка по дням, прогноз спроса (заявки/выручка, проекция), риски по срокам, предиктив ТОиР.
Контур: ПроизводствоОблако · роли · уведомления
Что вы получаете

Результат для компании

📈

Прогноз и аналитика L4: загрузка по дням (план-часы против мощности), ETA и риск просрочки по нарядам; прогноз спроса с линейной проекцией (app_forecast_demand); риски по срокам заявок (app_forecast_risks); предиктив ТОиР по наработке (app_mnt_runtime_status).

Возможности

Какие функции выполняются

  • Загрузка по дням (план vs мощность, %)
  • ETA по нарядам и риск просрочки
  • Прогноз спроса: заявки/выручка по месяцам + проекция (SVG)
  • Риски по срокам: просрочен/риск/норма
  • Предиктив ТОиР: остаток наработки до ТО
  • KPI: остаток часов, мощность, просрочено

Как реализовано

Модуль работает в облачном сервисе: данные хранятся в защищённой базе (Postgres), доступ — по ролям, обмен — через внутренние функции. Отдельной установки и обслуживания не требуется.
